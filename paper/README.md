# Supporting analysis tables

The canonical manuscript and manually edited figures are in [`../tmlr_paper`](../tmlr_paper).

`assets/tables/` and `assets_manual/tables/` retain the numerical tables and
analysis exports from the publication workflow. Some names use historical
figure/table numbering. Use the current LaTeX supplement for final numbering,
and the [extended archive manifest](../zenodo/floatsom_extended_supplementary/MANIFEST.tsv)
for archived supplementary results.

`assets/figures/` and `assets_manual/figures/` are ignored output directories for
analysis scripts. Their generated plots must not replace the manually edited
SVGs in `tmlr_paper/assets/figures/`.

Earlier Markdown drafts, duplicate rendered papers and submission bundles are
retired from the current tree. The LaTeX source is the publication source of truth.
